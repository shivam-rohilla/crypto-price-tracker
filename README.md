\# 📊 Crypto Data Tracker (INR)



Automated daily tracking of \*\*Bitcoin (BTC)\*\* and \*\*Ethereum (ETH)\*\* prices in \*\*Indian Rupees (INR)\*\* using GitHub Actions.



\## 🔧 How it works

\- Runs daily via GitHub Actions

\- Fetches real-time crypto prices from a public API

\- Commits \*\*only when prices change\*\*

\- No manual input required



\## 📁 Data

Stored in `data/prices.json` as a daily snapshot.
